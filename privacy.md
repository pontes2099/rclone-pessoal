# Política de Privacidade

Última atualização: 28 de setembro de 2026.

## Finalidade

O rclone-pessoal é um aplicativo de uso exclusivamente pessoal, utilizado para permitir que o proprietário acesse seu próprio Google Drive por meio do rclone.

## Dados acessados

O aplicativo poderá acessar arquivos, pastas e metadados do Google Drive somente após autorização expressa do proprietário da conta.

## Uso dos dados

Os dados são utilizados exclusivamente para listar, transferir, montar e gerenciar arquivos solicitados pelo próprio usuário.

## Armazenamento

O aplicativo não mantém servidor externo nem banco de dados próprio. As credenciais de autorização são armazenadas localmente no computador do usuário pelo rclone.

## Compartilhamento

Nenhuma informação acessada pelo aplicativo é vendida, compartilhada ou transferida a terceiros.

## Revogação

O usuário pode revogar o acesso a qualquer momento nas configurações de segurança de sua Conta Google.

## Contato

Este aplicativo é mantido exclusivamente para uso pessoal pelo proprietário da conta.
